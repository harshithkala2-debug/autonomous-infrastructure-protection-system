# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **"Report a vulnerability"** (Security Advisories)
feature on this repository. Do not open a public issue. Include reproduction steps and the affected version.
We aim to acknowledge reports within 5 working days.

## Scope

All code in `aips/`. See [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md) for the design assumptions.

## Authorised use

AIPS is defensive software. Run it only against systems you own or are explicitly authorised to operate and test.
